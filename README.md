# terminal

GPU-accelerated terminal emulator written in Rust (wgpu + libghostty-vt).

## Build

```sh
cargo run --release
```

Requires Rust stable and Zig 0.15.2. See [CONTRIBUTING.md](CONTRIBUTING.md).
